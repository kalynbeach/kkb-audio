## Contract and consequences

1. **Geometry:** repeat globally aligned converted PCM `[a,b)`, where requested source `[A,B)` maps
   to `a=ceil(A·Ro/Rs)`, `b=ceil(B·Ro/Rs)`. Let `P=b−a` and
   `F=min(floor(Ro/200),floor(P/4))`. Only tail frames `b−F+j` change:
   `y=(1−j/(F−1))·x[b−F+j]+j/(F−1)·x[a]`. The head contribution is one **held** value,
   not a moving-head crossfade. The final tail value equals the head; the original final tail sample
   has zero weight. All P timeline frames remain. Outside that tail, no PCM is skipped or duplicated.
2. **Bounds:** require P≥8 and F≥2. The fade is at most 5 ms and at most one quarter of the interval.
   Reject too-short/unsupported regions without changing accepted boundaries or linear playback.
   No zero-crossing movement. Exact source-frame fields make sub-millisecond legal regions editable.
3. **Grid:** preserve the **realized output period**, not exact requested source duration. Each
   iteration's error is less than one output frame, but cumulative error is unbounded. No fractional
   phase scheduling, alternating periods, or new converter quality claim. UI details separate both
   coordinate/rate/duration pairs and the floor-mapped realized start cursor.
4. **Controls:** whole-track/off on load; disclosure independent of enable; Disabled/Preparing/Armed/
   Active/Failed. Enable outside chooses a without starting paused audio. Enable inside and disable
   retain the exact next-to-render PCM. An enabled edit excluding the acknowledgment-time cursor
   disables without relocating; user seek outside (including B) disables. Reset edits to the whole
   track; it does not independently force enable off. New tracks reset whole/off, keeping disclosure.
   One executing preparation and one replaceable latest request, not an accumulating command queue.
5. **Readiness/failure:** head and initial supply must be ready before Armed. Normal wraps never use
   public seek, UI polling, EOS restart, or a new render instance. Armed starvation latches
   LoopUnderrun, holds media position, emits F last-value→zero steps, then silence, and re-primes exact
   a under a fresh epoch. Fade-out weights are `(F−1−j)/F`; fade-in weights are `(j+1)/F`.
   Render time continues except when explicitly paused. Track I/O/decode/worker corruption instead
   terminates playback and reports loop Failed; recovery is explicit track retry/reload.
6. **Coordinates/state:** source identity, control epoch, loop iteration, media PCM and render frame
   remain distinct. First/last consumed iteration and seam-frame count bound contribution reporting,
   including multiple wraps per callback. Tail coordinates stay authoritative during smoothing;
   held-head contribution is at a, incoming iteration, same source/epoch. Downstream render state
   is retained. No public automation or canonical tagged analyser API was added.

Held-head smoothing changes slopes and can distort an already-periodic waveform or introduce DC
bias. Convex mixing preserves an existing constant signal within f32 rounding; it does not preserve
all waveform shapes. The tests explicitly demonstrate that limitation. Representative listening is
still required before describing audible seams as smooth.

## Implementation and bounds

- `src/wav_loop.rs`: shared worker-owned loop head and converter continuation; `sample_rate.rs`
  adds exact output-grid re-prime. Head is at most 4096 frames (maximum stereo storage 32 KiB).
  It uses the incumbent preceding global FFT chunk and at most two input chunks of pre-roll;
  the declared head storage is not a claim that converter working memory is zero.
- `src/prepared_pcm.rs`: shared post-resample/pre-downstream smoothing, wrapped media mapping,
  bounded contribution counters, failure ramps and recovery. Four incumbent 1024-frame transport
  slots remain. Renderer head state is only a stereo value plus scalar region/counters; no full head
  allocation, decoding, I/O, wait or ownership destruction in the callback.
- Native host owns file reads/conversion/rings and a bounded coherent scalar command publication.
  Its callback acknowledges exact PCM, reclaims through the return ring, preserves one compiled
  instance and publishes recovery; worker reconstructs supply. No native UI was introduced.
- Browser producer/worker use the same Rust loop preparation and four-slot transport. The private
  begin/head/finish handshake identifies both epoch and captured PCM. Latest-work checks cover
  read completion, head and finish; stale work cannot arm a superseded region. Actual worker and
  Wasm tests exercise this path, not the prototype reducer.
- Worklet memory remains fixed at 256 initial/maximum pages = **16,777,216 bytes**. Normal wrap and
  recovery use fixed storage. Allocator probes cover shared seam/starvation/fade-in and native
  loop-change/arming/recovery publication, as well as existing error/retirement paths, with zero
  observed allocation, zeroed allocation, reallocation or deallocation calls.
- Source waveform generation, original amplitude and identity are unchanged. Normal wraps leave the
  private pre-volume analyser continuous; explicit changes/recovery invalidate source observations
  and visual history. Its trailing window remains approximate, untagged and not speaker-synchronized.

Underrun count and extension frames accumulate over a render instance; discarded remaining nominal
PCM describes the last failure. Explicit region changes reset iteration numbering, not those failure
counters. A cursor at a immediately after a wrap can coexist with the prior last-consumed iteration
until the first new head frame is rendered. These are bounded summaries, not a per-frame event API.
